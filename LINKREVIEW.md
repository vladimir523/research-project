# Обзор литературы

### 1. Connor et al., 2026

[Beyond Feature Importance: A Comparative Analysis of Pattern Detection Methods in Cluster Interpretation](https://arxiv.org/html/2608.05880v1). Препринт, arXiv:2608.05880.

Сравниваются RF, LIME и PCA на синтетических данных с внедрёнными паттернами. Успешное выделение отдельных признаков не гарантирует восстановления отношений между ними. Работа задаёт основу нашего сравнения; отдельно исследуем изменение рейтингов при усилении различий средних.

### 2. Ribeiro, Singh, Guestrin, 2016

[“Why Should I Trust You?”: Explaining the Predictions of Any Classifier](https://arxiv.org/abs/1602.04938). KDD 2016.

Предложен LIME — локальная интерпретируемая модель, приближающая предсказания классификатора. Локальное объяснение относится к конкретному объекту, поэтому для анализа группы требуется способ объединения объяснений. В нашем эксперименте важно проверять как агрегированный рейтинг, так и качество локального приближения.

### 3. Strobl et al., 2008

[Conditional variable importance for random forests](https://link.springer.com/article/10.1186/1471-2105-9-307). BMC Bioinformatics, 9:307.

Показано, что зависимости между предикторами влияют на permutation importance; предложены условные перестановки. Следовательно, важность зависит не только от обученной модели, но и от процедуры её измерения. Это необходимо учитывать при анализе рейтингов коррелированных признаков.

### 4. Wilming et al., 2022

[Scrutinizing XAI using linear ground-truth data with suppressor variables](https://link.springer.com/article/10.1007/s10994-022-06167-y). Machine Learning, 111:1903–1923.

На синтетических данных сравниваются методы объяснения при наличии переменных, улучшающих прогноз за счёт подавления шума. Показано расхождение между важностью для модели и статистической связью с целевой переменной. Для нашего исследования полезен принцип проверки объяснений относительно известного генератора данных.

## Выделение взаимодействий

### 5. Blum et al., 2025

[Pure interaction effects unseen by Random Forests](https://arxiv.org/abs/2406.15500v2). Препринт, версия 2025 года.

Исследуются ограничения стандартного RF при чистых взаимодействиях и варианты построения деревьев, улучшающие их обнаружение. Работа показывает необходимость разделять два источника потери сигнала: модель могла недостаточно изучить взаимодействие либо способ оценки важности мог его слабо отразить.

### 6. Hornung, Boulesteix, 2022

[Interaction forests: Identifying and exploiting interpretable quantitative and qualitative interaction effects](https://doi.org/10.1016/j.csda.2022.107460). Computational Statistics & Data Analysis, 171:107460. [Авторский препринт](https://epub.ub.uni-muenchen.de/75432/1/TR.pdf).

Предложены леса с разбиениями по двум признакам и отдельной оценкой важности взаимодействий. В отличие от обычного рейтинга признаков, метод ранжирует пары. Это возможный дополнительный метод сравнения при переходе от выделения участников паттерна к обнаружению самой пары.

### 7. König, Günther, von Luxburg, 2025

[Disentangling Interactions and Dependencies in Feature Attributions](https://proceedings.mlr.press/v258/konig25a.html). AISTATS, PMLR 258:2134–2142.

Предложено разложение DIP, разделяющее самостоятельный вклад признака, взаимодействия и статистические зависимости. Единая оценка важности смешивает эти компоненты. Работа даёт основу для анализа того, почему изменение одного сигнала может менять интерпретацию остальных признаков.

### 8. Lazic et al., 2025

[Information-theoretic Quantification of High-order Feature Effects in Classification Problems](https://arxiv.org/html/2507.04362v1). Препринт, arXiv:2507.04362v1.

Информационные вклады разделяются на уникальные, совместные и избыточные. Среди синтетических примеров рассматривается сочетание межгрупповых различий средних и корреляций. Такой подход позволяет анализировать структуру сигнала без привязки к конкретному классификатору и дополняет сравнение модельных объяснений.

### 9. Chen et al., 2025

[Error-controlled non-additive interaction discovery in machine learning models](https://www.nature.com/articles/s42256-025-01086-8). Nature Machine Intelligence, 7:1541–1554.

Метод Diamond выделяет неаддитивные взаимодействия и использует model-X knockoffs для контроля ложных обнаружений при соответствующих предположениях. В отличие от отбора top-k признаков, постановка включает статистический контроль найденных пар. Для нашей работы это ориентир при выборе дополнительных метрик обнаружения.

## Интерпретация структуры кластеров

### 10. Sirocchi, Urschler, Pfeifer, 2025

[Feature graphs for interpretable unsupervised tree ensembles: centrality, interaction, and application in disease subtyping](https://link.springer.com/article/10.1186/s13040-025-00430-3). BioData Mining, 18:15.

Из структуры unsupervised random forest строятся графы признаков для всей выборки и отдельных кластеров. Рёбра отражают совместное использование признаков при разделении данных, а не непосредственно их корреляции. Подход показывает альтернативу интерпретации кластеров через классификатор, обученный на готовых метках.
