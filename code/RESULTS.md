# Первый эксперимент: конкуренция сдвига среднего и корреляционного сигнала

Дата: 23 октября 2026. Реально выполненный разведочный пилот; научная новизна не объявляется установленной.

## Что было сделано

20 независимых пар обучающих и тестовых наборов, по 600 объектов и 10 признаков в каждом наборе. В каждой группе по 300 объектов. Корреляция X,Y: 0.8 в A и 0 в B. Разница средних Z последовательно равна 0, 0.5, 1, 2, 3 и 4. Это 120 условий с обученным RF и 720 записей результатов шести способов ранжирования, но только 20 независимых повторов. Условия спарены: меняется только Z. Методам сообщается готовое разбиение, алгоритм кластеризации не запускается.

## Первые результаты

Основная метрика — оба признака X и Y попали в top-3 из 10. В скобках указан 95% интервал Wilson по независимым повторам. При случайном рейтинге вероятность составляет 6.7%.

| Метод | Δ=0 | Δ=4 |
|---|---:|---:|
| RF: permutation importance по accuracy | 100% [83.9; 100.0] | 0% [0.0; 16.1] |
| RF: permutation importance по log-loss | 100% [83.9; 100.0] | 70% [48.1; 85.5] |
| LIME: усреднённые абсолютные веса | 5% [0.9; 23.6] | 5% [0.9; 23.6] |
| PCA с общей стандартизацией | 100% [83.9; 100.0] | 100% [83.9; 100.0] |
| PCA с центрированием и стандартизацией внутри групп | 100% [83.9; 100.0] | 100% [83.9; 100.0] |
| Прямой анализ различий корреляций | 100% [83.9; 100.0] | 100% [83.9; 100.0] |

Тестовая accuracy RF: 0.578 при Δ=0 и 0.978 при Δ=4. Точность правила, использующего истинные распределения: 0.687 и 0.983 соответственно.

Средний R² локальных аппроксимаций LIME: 0.100 при Δ=0 и 0.347 при Δ=4. Это диагностический показатель верности локального линейного приближения, а не точность восстановления паттерна.

## Как интерпретировать

1. Высокий ранг Z корректен: Z действительно различает группы. Цель опыта — полнота восстановления известного устройства данных, которая отличается от объяснения поведения модели.
2. Сравнение двух важностей одного и того же RF помогает проверить, связана ли потеря пары с выбором метрики. Accuracy меняется только при смене предсказанного класса; log-loss чувствителен также к изменениям вероятностей.
3. Если LIME редко восстанавливает пару уже при Δ=0, его результат при Δ=4 нельзя объяснять исключительно конкуренцией Z. Здесь проверена конкретная квартильная дискретизация и усреднение по восьми объектам; вывод обо всём LIME не следует.
4. Внутригрупповое центрирование PCA убирает добавленный сдвиг Z. Этот вариант служит контролем механизма; его неизменность — ожидаемое свойство, не открытие.
5. Прямой анализ корреляций решает задачу непосредственно. Статистические проверки относятся к заранее заданным группам; они не получают автоматически корректности после реального K-means.

Файл paired_change.csv дополнительно содержит спаренный percentile bootstrap. При одинаковых изменениях во всех 20 повторах его интервал вырождается в точку; это не означает отсутствие популяционной неопределённости. Частоты выше снабжены интервалами Wilson.

## Негативный контроль

- При одинаковых корреляциях обеих групп и Δ=0: 0 из 20 наборов содержат хотя бы одну значимую пару после Holm при α=0.05.
- При одинаковых корреляциях обеих групп и Δ=4: 0 из 20 наборов содержат хотя бы одну значимую пару после Holm при α=0.05.

Один и тот же контрольный набор используется при двух значениях Δ; это 20 независимых наборов, а не 40 независимых повторов.

## Ограничения и решение о следующем шаге

Пилот проверяет выполнимость конкретной постановки. Высокая корреляция 0.8, одна размерность, 20 повторов и небольшая выборка локальных объяснений не дают общего вывода обо всех режимах. Из top-3 признаков нельзя заключить, что метод восстановил правильную пару, знак связи или причинную зависимость.

Для следующего исследования полезнее проверять конкретный механизм различий между метриками важности RF и способами агрегации объяснений. Общий тезис «сильные различия средних скрывают корреляции у всех методов» не должен приниматься заранее. Улучшение над сильным прямым baseline в этом опыте не заявляется.
